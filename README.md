# M67-Cluster-Astro-Pipeline
## 项目简介
M67疏散星团FITS天文图像自动化处理流程，基于Astropy、Photutils库，
本项目为报考中国科学院新疆天文台天文技术与方法方向准备，实现天文观测图像预处理与测光。

## 功能
1. FITS图像读取与裁剪
2. 二维背景估计与背景扣除
3. 图像恒星源检测
4. 恒星光度测量（孔径测光）

## 依赖环境
pip install astropy photutils numpy matplotlib
## 使用方法
1. 从MAST数据库下载M67星团FITS观测图像
2. 修改代码内FITS文件路径
3. 运行：`python M67.py`

## 输出结果
- 背景扣除后的干净天文图像
- 检测到恒星源位置列表
- 每颗恒星的孔径测光星等

## 项目说明
M67是著名老年疏散星团，常用于恒星演化研究。
本流程复现天文台基础天文图像处理归算流程，熟悉光学观测数据 reduction，
是天文技术方向常用的基础数据处理任务。
